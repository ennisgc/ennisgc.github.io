Choir "aah" samples: from the FluidR3_GM soundfont ("Choir Aahs"), as rendered per note by midi-js-soundfonts
(https://github.com/gleitz/midi-js-soundfonts), Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/).
One note every minor third (same names as samples/piano). Each was made mono, normalised, trimmed to 3.1 s and
given a cross-faded seam so keyboard.js can loop it from 0.9 s to 3.1 s while a key is held (LOOP_START / LOOP_END).
